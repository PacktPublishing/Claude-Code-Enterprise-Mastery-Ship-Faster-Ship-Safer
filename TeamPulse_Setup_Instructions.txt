TeamPulse Demo Project — Setup Instructions

Repository: https://github.com/aiguru-one/teampulse

To follow along with the capstone:

1. git clone git@github.com:aiguru-one/teampulse.git
2. cd teampulse
3. git checkout v1.0-unconfigured
4. npm install

The v1.0-unconfigured tag gives you a clean starting point
with zero Claude Code configuration — exactly what we build
from scratch in this section.

Requirements:
- Node.js 20+
- Git
- Claude Code installed and authenticated
